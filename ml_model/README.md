# Atmosync ML Module

Machine learning components for climate anomaly detection and weather forecasting.

## Components
- Climate anomaly detection
- Seven-day forecast processing
- Extreme-weather risk prediction
- Data validation and preprocessing
- Model training and evaluation

## Data principles
- Preserve original downloaded data.
- Validate records and document missing values.
- Prevent data leakage during model evaluation.
- Document data sources and model limitations.

All ML-related work belongs inside this directory.
